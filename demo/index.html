KitKat demo pages

Point the extension at any of these to exercise the Validator and Debugger.

Each demo is a real WebMCP page. In Chrome 146+ with the WebMCP flag on, the native navigator.modelContext is used; otherwise the bundled KitKat polyfill stands in so tools are still discoverable. Either way, open DevTools → KitKat (or the popup) to inspect them.
🛍️ E-commerce
Imperative + declarative tools: search, cart, subscribe.
✈️ Travel
Read-only search + a mutating book tool that requests consent.
📝 Forms
Pure declarative tools — forms become tools with no JS.
